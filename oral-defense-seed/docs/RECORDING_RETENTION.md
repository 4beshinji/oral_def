# 会話中の録音保存契約

2026-09-29。対象は会話画面の単独復唱とお手本同時録音。

- 単独復唱は会話を一時停止し、現在の不変な参照文に対して開始する。録音開始時のexercise IDを固定し、会話が次ターンへ進んでも変更しない。録音・upload・評価の完了は会話進行を待たせない。
- 同時録音はお手本再生中だけ開始でき、お手本音声を止めない。正常再生完了または一時停止時にマイクを閉じ、次の相手音声を録らない。録音条件は`shadowing_overlap`で保存し、本人だけの音声とみなして採点しない。
- 最長29.5秒で録音を停止する。停止時にBlob、元session/exercise ID、録音条件、再送キーをIndexedDBへ保存する。保存成功後に同じキーでuploadする。upload失敗ではBlobを残し、再読込・セッション切替後も再送できる。成功時だけ削除する。同じキーの再送はサーバーで一attemptへまとめる。
- IndexedDBへの保存が失敗した場合は、その画面を開いている間だけBlobを保持し、エラーを表示する。画面を閉じると失われる。録音中の再読込・タブ終了でも未停止の音声は失われる。
- 保存待ち録音は明示破棄、upload成功、画面からのセッション削除、次回起動時にサーバーに存在しないセッションの清掃で削除する。期限による自動削除はしない。ブラウザの保存容量制限、プライベートモード、サイトデータ削除では保持できない。IndexedDBはbackup/exportに含まれない。
- サーバーは10 MiB以下の録音だけを受け取る。保存したattemptは元exerciseに属し、共有exportでは録音有無・条件・評価状態を参照文と区別して出す。実音響評価器が未設定なら点数を出さない。

会話画面の録音失敗→再読込→同じキーで再送→評価状態のChrome試験と、同sessionで次ターンへ進んだ後の遅延upload/評価のAPI試験を検証根拠とする。ブラウザ障害・電源断・端末間同期は保証しない。

## 自由発話の録音

最大29秒で自動停止し、session/turn IDと再送キーを別のIndexedDB領域に保存する。upload成功までブラウザに保持し、成功後はサーバーの録音一覧から同じ録音を再認識できる。無音・認識失敗でもサーバー上の録音は削除しない。セッション削除ではサーバー保存分も削除する。ブラウザ内の未送信Blobはサイトデータ削除で失われる。途中でモードを変更した場合、元turnの録音として保持するが、旧認識結果で新モードの返答を確定しない。人間マイクでの保存・再送は未検証。
