# 受け入れ条件

2026-09-15。[ADR](adr/0001-coach-led-shadowing.md)と[設計](DESIGN.md)に対する目標。標準ループの状態制御を自動試験済み。実provider品質・録音を含む全条件の合格は未達（[検証記録](VALIDATION.md#2026-09-15-coach主導の標準ループ)参照）。VALIDATION.mdのAC番号は既存実装の試験識別子で、以下の合格証拠ではない。

| ID | 条件 | 合格する挙動 | 検証 |
|---|---|---|---|
| SH01 | 場面・Packを選び開始 | 6往復以上自動継続。毎回の編集・承認・採点確認不要 | 実LLM/TTS/画面 |
| SH02 | 録音なしでお手本が正常終了 | 参照文をshadowing_playbackとして一度だけ確定し次へ | API/E2E |
| SH03 | TTS生成・取得、相手音声やプレビュー終了 | 本人の返答を確定しない | 状態テスト |
| SH04 | 再生拒否・中断・失敗、音声片の途中終了 | 未確定のまま復帰可能。全体正常終了でのみ確定 | 故障注入 |
| SH05 | 重複・旧版・取消済み・別sessionの完了 | 二重返答・二重turnなし。不正な関連付けを拒否 | API |
| SH06 | マイク拒否・upload失敗・採点遅延 | 会話は継続し、保存待ち録音と評価は元試行に残る | API/E2E |
| SH07 | Coach私的履歴にsentinel | 再生前は案を送らず、完了後は採用文のみ公開。私的履歴は非公開 | builder/provider境界 |
| SH08 | 確定後に次の生成が失敗 | 確定返答を保持。再試行で重複せず生成再開 | API/E2E |
| SH09 | pause・再読込・session変更 | 停止後に勝手に進まない。未通知の完了を推測しない | E2E |
| SH10 | 懇親会とゼミで同じ資料 | 場面に応じた会話。未知の本人の成果や読めないプレースホルダなし | 実LLM固定例 |
| SH11 | URL/PDF取り込みと抽出失敗 | 出典位置・版を追跡。失敗資料を取得済みにしない | 文書fixture/API |
| SH12 | 再生だけの返答をexport | 参照文・録音有無・transcript・確定元を区別。秘密情報なし | API |
| SH13 | お手本混入録音・未設定評価器 | 本人単独の正確な発音点数を出さず理由表示。単独復唱が可能 | 実録音/fixture |
| SH14 | 字幕・意味・速度・反復 | 個別調整可能。過去のお手本再生で会話は進まない | E2E |
| SH15 | 削除・不正音声ID・再録音 | 子データ/音声削除、所属検証、参照文不変、別attemptを維持 | 回帰テスト |
| SH16 | 6往復・Coach12回超 | 入力上限を管理して継続または次区間へ進める | API/実LLM |
| FS01 | 自由発話終了・認識成功 | 最終transcriptのみ一度確定し自動応答 | API/実録音 |
| FS02 | 無音・空transcript・ASR失敗 | お手本で代用せず未確定。録音保持と再試行・代替入力 | 故障注入 |
| FS03 | お手本と異なる自由発話 | 厳密な発音点数を出さず、不一致で減点しない | API/UI |
| FS04 | 停止中にモード変更、旧通知到着 | 入力を混同せず確定履歴を変更しない | API/E2E |

生成品質は固定ケースの実出力で確認し全文完全一致を求めない。状態制御とcontext境界は決定的に検証する。音響精度はDESIGN §7とP0報告で別に判定し、mockやASR一致を代用しない。
